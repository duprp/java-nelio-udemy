# Matriz

Lê as dimensões e os valores de uma matriz de inteiros e um número a procurar; para cada ocorrência, mostra a posição e os vizinhos à esquerda, direita, acima e abaixo (quando existem e são diferentes de zero).

**Conceitos:** matriz (`int[][]`), laços `for` aninhados, condicionais com verificação de limites, `Scanner` e `Locale`.
