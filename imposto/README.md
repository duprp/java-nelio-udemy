# imposto

Lê dados de contribuintes (pessoa física ou jurídica), calcula o imposto de cada um conforme a renda anual, os gastos com saúde ou o número de funcionários, e mostra o valor pago por contribuinte e o total arrecadado.

**Conceitos:** classes abstratas, herança, polimorfismo (`@Override` de `imposto()`), `List`/`ArrayList`, `Scanner`, `String.format`.
