# cadastro

Menu de console para gerenciar usuários em memória: cadastrar (nome, sobrenome, CPF e data de nascimento), editar, consultar um usuário pelo CPF ou listar todos, e excluir com confirmação.

**Conceitos:** classes de entidade com encapsulamento (getters/setters), classe repositório com `List`/`ArrayList`, busca e remoção por CPF, `LocalDate` com `DateTimeFormatter`, text blocks (`"""`), laço `while` com menu, `Scanner`, sobrescrita de `toString()`, pacotes, projeto Maven.
