# logAcess

Lê um arquivo de log de acessos (`acessos.txt`), pega o nome de usuário no início de cada linha e mostra quantos usuários distintos acessaram.

**Conceitos:** `Set`/`HashSet` para eliminar repetidos, leitura de arquivo com `Files.newBufferedReader` e `Path`, try-with-resources, tratamento de `IOException`, `String.split`.
