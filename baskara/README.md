# baskara

Lê os coeficientes B, A e C de uma equação do 2º grau e calcula as duas raízes pela fórmula de Bhaskara, mostrando os valores de X. Escrito em Kotlin.

**Conceitos:** funções em Kotlin (incluindo função local dentro de `main`), `readln()` com conversão `toDouble()`, `val`, `kotlin.math.sqrt`, string templates (`$variavel`).
