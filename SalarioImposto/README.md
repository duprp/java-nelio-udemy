# SalarioImposto

Lê o nome, o salário bruto e o imposto de um funcionário, mostra o salário líquido e depois aplica um aumento percentual sobre o salário bruto, exibindo os dados atualizados.

**Conceitos:** classes e objetos, atributos e métodos de instância, `toString()`, `Scanner`, `Locale`, `String.format`.
