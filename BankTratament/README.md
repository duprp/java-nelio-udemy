# BankTratament

Lê os dados de uma conta bancária (número, titular, saldo inicial e limite de saque) e tenta realizar um saque: se o valor passar do limite ou do saldo, mostra a mensagem de erro; caso contrário, mostra o novo saldo.

**Conceitos:** tratamento de exceções com `try/catch`, exceção personalizada (`DomainException` estendendo `RuntimeException`), `throw`/`throws`, validação de regras de negócio na entidade, encapsulamento, `Scanner`, `printf`, projeto Maven.
