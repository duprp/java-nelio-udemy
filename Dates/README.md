# Dates

Demonstra operações com datas: formata uma data no padrão `dd/MM/yyyy`, compara a data atual com outra, calcula a diferença em anos, meses e dias entre duas datas digitadas e soma/subtrai semanas, meses, anos e dias da data de hoje.

**Conceitos:** `LocalDate`, `DateTimeFormatter`, `Period.between`, `isBefore`/`isEqual`, `plusWeeks`/`plusMonths`/`minusDays`, `Scanner`.
