# Pedidos

Cadastra um cliente e um pedido (com status informado pelo usuário), adiciona N itens com produto, preço e quantidade, e imprime o resumo do pedido com subtotais e preço total.

**Conceitos:** classes e encapsulamento, composição de objetos (Order → OrderItem → Product, Order → Client), `enum` com construtor (`OrderStatus.valueOf`), `List`/`ArrayList`, `Date` e `SimpleDateFormat`, `StringBuilder`, sobrescrita de `toString`.
