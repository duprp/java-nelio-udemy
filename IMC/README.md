# IMC

Lê o peso e a altura do usuário, calcula o Índice de Massa Corporal (peso / altura²) e informa a faixa correspondente (abaixo do peso, peso normal, sobrepeso ou obesidade), exibindo o valor com duas casas decimais. Escrito em Kotlin.

**Conceitos:** funções com parâmetros, `readln()` e conversão com `toDouble()`, estrutura condicional `if`/`else if`, operadores lógicos, formatação com `"%.2f".format(...)`.
