# Pensionato

Lê quantos quartos serão alugados e, para cada aluguel, o nome, o e-mail e o número do quarto do hóspede. Depois ordena as reservas pelo número do quarto e lista os quartos ocupados.

**Conceitos:** classes e encapsulamento (getters/setters), construtor, vetores de objetos, `Arrays.sort` com `Comparator.comparing`, `Scanner`, laço for-each.
