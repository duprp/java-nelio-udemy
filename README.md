# ☕ Java — Curso Nelio Alves (Udemy)

Exercícios e mini-projetos que desenvolvi durante o curso **Java COMPLETO — Programação Orientada a Objetos** do professor Nelio Alves, na Udemy.

O repositório acompanha a minha evolução: começa com estrutura sequencial, condicionais e laços, passa por vetores e matrizes, e chega em POO, tratamento de exceções, coleções (`Set`, `Map`), datas e manipulação de arquivos.

### Como rodar

Cada pasta é um projeto independente. Os projetos Maven (com `pom.xml`) podem ser abertos direto no IntelliJ IDEA; os demais têm o código-fonte na pasta `src/`.
