# Aumento

Cadastra uma lista de funcionários (id, nome e salário), pede o id de um deles e aplica um aumento percentual ao salário, avisando se o id não existir; no fim, imprime todos os funcionários.

**Conceitos:** classes e objetos, construtor, `List`/`ArrayList`, laço `for` e for-each, busca de posição em lista retornando `Integer` (com `null`), `Scanner`, `toString()` com `@Override`.
