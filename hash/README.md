# hash

Cria dois objetos `Client` com nome e e-mail diferentes e imprime seus `hashCode`, o resultado de `equals` e a comparação por referência (`==`).

**Conceitos:** classes e encapsulamento (getters/setters), sobrescrita de `equals` e `hashCode` com `Objects.equals`/`Objects.hash`, `@Override`, diferença entre `equals` e `==`.
