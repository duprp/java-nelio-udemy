# BankAccount

Cria uma conta bancária com número e titular, com depósito inicial opcional, e em seguida registra um depósito e um saque (que cobra uma taxa de 5,00), mostrando os dados da conta após cada operação.

**Conceitos:** encapsulamento (atributos `private`, getters e setters), construtor, `toString()` com `@Override`, `String.format`, `Scanner` e limpeza de buffer, condicional `if/else`.
