# Alfandega

Lê uma quantidade de produtos, cada um comum, usado ou importado, e imprime as etiquetas de preço: produtos importados somam a taxa de alfândega ao preço e produtos usados mostram a data de fabricação.

**Conceitos:** herança, sobrescrita de métodos (`@Override`), polimorfismo, `List`/`ArrayList`, `Scanner`, datas com `SimpleDateFormat` e `Date`, `ParseException`.
