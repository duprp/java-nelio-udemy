# consolecalculator

Calculadora de console: mostra um menu (somar, subtrair, dividir, multiplicar), lê a opção e dois números e imprime o resultado calculado pela classe `Operacoes`. Entradas inválidas são capturadas e o programa exibe "error".

**Conceitos:** classes e métodos, `Scanner`, text blocks (`"""`), `if/else`, tratamento de exceções com `try/catch`, tipo `float`.
